# RNG Slot Generator – Personal Unity Project

An interactive RNG (random number generator) slot machine-style application developed in Unity. Inspired by arcade aesthetics, the app showcases basic real-time interactivity, multiplier logic, and visual polish using Unity UI tools.

## About the Game

This RNG application simulates a slot-style number generator where users can initiate and stop number rolls with a click. Multipliers ranging from 1x to 4x modify the output range dynamically (up to 400). The interface draws on cyberpunk and casino themes for visual appeal.
## Technologies Used

- **Game Engine:** Unity
- **Version Control:** Git & GitHub
- **Scripting:** C# (Visual Studio Code)
- **Design Tools:** AI-generated artwork, custom UI elements
- **Sound:** Freesound.org audio assets

---

## My Role

I designed and built this project independently with a focus on:

- **Core Functionality:** Developed the RNG logic using Random.Range() and integrated multiplier scaling
- **UI Scripting:** Created start/stop functionality and real-time number display using Unity’s UI system
- **Visual Design:** Designed slot-machine-inspired visuals using AI-generated assets
- **Audio Integration:** Sourced and implemented feedback SFX from royalty-free sound libraries
- **User Experience:** Tuned animations and transitions for a satisfying arcade feel.

---

## Challenges Faced

- **Real-Time Syncing:** Ensuring numbers updated responsively without overloading the frame rate
- **Multiplier Logic:** Designing clean, readable code to scale output range dynamically
- **Visual Clarity:** Balancing stylistic flair with legible number presentation
- **Design Consistency:** Making UI cohesive across varying resolutions and devices
